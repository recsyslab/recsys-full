## データベースの準備

ここでは、データベースにアクセスするユーザ名を`rsl`、ログインするためのパスワードを`rsl-pass`としています。適宜、変更してください。


`src/backend/config/settings/development.py`

```py
from .base import *
import os
import logging

# ローカル開発専用の既定鍵（DJANGO_SECRET_KEY が未設定の場合のみ使用。本番では使用不可）。
if not SECRET_KEY:
    SECRET_KEY = 'django-insecure-local-dev-only-do-not-use-in-production'

DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.postgresql',
        'NAME': 'recsys_full',
        'USER': os.environ.get('DB_USER'),
        'PASSWORD': os.environ.get('DB_PASSWORD'),
        'HOST': '',
        'PORT': '',
    }
}

class SQLColorFormatter(logging.Formatter):
    LOG_COLOR = "\033[96m"
    RESET = "\033[0m"

    def format(self, record):
        message = super().format(record)
        return f"{self.LOG_COLOR}{message}{self.RESET}"

LOGGING = {
    'version': 1,
    'disable_existing_loggers': False,
    'formatters': {
        'colored_sql': {
            '()': 'config.settings.development.SQLColorFormatter',
            'format': '%(levelname)s %(message)s',
        },
    },
    'handlers': {
        'console': {
            'class': 'logging.StreamHandler',
            'formatter': 'colored_sql',
        }
    },
    'loggers': {
        'django.db.backends': {
            'level': 'DEBUG',
            'handlers': ['console'],
        }
    }
}
```
